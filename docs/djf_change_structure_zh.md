# 冬季西南涡变化结构与来源分解：第四阶段A报告

更新日期：2026-09-06

## 1. 问题与预设方法

本阶段检验1980–2023年DJF频数和强度上尾的变化是持续线性趋势、年代际转折还是近期加速，并把频数趋势分解到12月、1月、2月及既有3个路径簇。主端点为频数，次端点为P90高度亏损和P90涡度。

基准使用HAC线性趋势；稳健性使用Theil–Sen斜率及3年、5年残差移动块bootstrap。分段模型只允许一个连续斜率转折，候选年限制为1990–2013年。转折由BIC选择，但其显著性在零假设模拟中每次重新搜索全部候选年，从而校正事后选择。2000年前后加速是上一阶段产生的探索性假设，不视为独立预设验证。

## 2. 主要结果

### 2.1 当前不支持一个确定的冬季转折点

频数分段搜索选择2013年，但分段模型BIC比线性模型更差（线性减分段ΔBIC=−1.54），选择后bootstrap p=0.304。P90高度亏损选择1997年，ΔBIC=−0.06、p=0.095；P90涡度选择1996年，ΔBIC=−1.96、p=0.446。三个端点均不足以拒绝线性变化。

因此，图中的分段线只能用于展示被搜索到的候选结构，不能称为气候突变。当前最稳妥结论仍是1980–2023年冬季频数持续增加和强度上尾增加；近年较陡只能作为待独立记录验证的线索。

### 2.2 稳健趋势不依赖普通最小二乘

- DJF频数Theil–Sen斜率为+1.67个/10年，3年和5年残差块区间分别为0.83–2.45和0.92–2.47个/10年。
- P90高度亏损Theil–Sen斜率为+0.508 gpm/10年，两个块长区间分别为0.168–0.835和0.171–0.822 gpm/10年。
- P90涡度Theil–Sen斜率约+0.07×10⁻⁴ s⁻¹/10年，两个区间均为正。

这些结果与此前HAC和移动块回归一致，说明方向不由单个极端年份或普通最小二乘估计方法决定。

### 2.3 月份分解以2月证据最强

DJF总频数的绝对线性增加约由12月、1月和2月分别贡献30.5%、38.8%和30.6%。但相对率趋势及多重检验结果不同：

- 2月：+7.01%/10年，HAC 95% CI 1.93%–12.33%，月内FDR p=0.019；
- 1月：+7.93%/10年，原始p=0.048，FDR p=0.071；
- 12月：+8.55%/10年，但区间−2.68%–21.09%，FDR p=0.141。

三个自然月的绝对贡献相近，但由于12月年际波动和离散度更大，目前只有2月在月份模型族中稳定保留。不能把DJF趋势简化成“仅2月增加”。

### 2.4 增加来自Cluster 1事件数，而不是显著路径比例转移

四川盆地附近局地型Cluster 1频数增加9.68%/10年，FDR p<10⁻¹²；其绝对斜率为+1.53个/10年，约等于DJF总趋势。Cluster 0和Cluster 2频数趋势接近零。

然而，3个路径簇的年度比例均未通过FDR，生成纬度、生成经度、最大经度、净位移、东移逸出比例和移动东移型比例也均未通过连续路径指标族FDR。生成经度原始p=0.021，但校正后p=0.127。

因此应解释为“Cluster 1所代表的四川盆地局地事件整体变多”，而不是有证据表明冬季路径构成显著转移。由于聚类轮廓系数仅0.314，Cluster 1结果仍需生成区连续定义和独立资料复核。

## 3. 对原课题的意义

冬季信号现在被进一步限定为：事件数增加集中于四川盆地局地型，同时没有检测到相应的东移比例或连续路径位置趋势；强度变化主要出现在分布上尾。它更像“局地生成机会和强事件尾部的增强”，而不是“西南涡整体向东移动并普遍增强”。

该结果为下一步环流诊断提供了更明确的目标：冬季应优先研究四川盆地局地生成环境、2月背景环流以及高分位强度条件，而不是先从东移引导气流入手。

## 4. 限制

- 断点搜索只有44年，选择后检验功效有限；未发现显著断点不等于证明完全线性。
- 2013年和1997年前后候选结构由同一记录搜索得到，不能在同一数据上再次包装成预设假设。
- 月份和路径分解涉及较小计数；FDR降低假阳性，但也降低检验功效。
- Cluster 1依赖既有K-means分类，尚未由独立资料或生成区阈值确认。
- 这些仍是观测年代变化，不是温室气体归因结果。
