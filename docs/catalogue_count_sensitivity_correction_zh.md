# 目录排除敏感性输入修正记录

2026-09-15，重新运行前记录。发现旧 `analyze_catalogue_count_sensitivity.py` 使用完整季节年匹配表（5,106条），而非9,513条全目录。该表已裁掉1979年非12月和2023年12月，使“1979--2023全年”频数斜率错误地变成+3.55事件/十年，与正文全5221事件+0.63不同。这个缺陷不在正文主频数分析，而在额外排除敏感性。

修正为从全 `events.csv` 读取9,513条，单独构造season-year，断言全年1979--2023计数5221。删除134条的均匀抽样仍为2000次、seed20260912；两个端点压力试验保持删除最早/最晚134条合格事件。旧三个输出保留作为无效历史，不用作论文证据；修正输出名称增加 `_corrected_`，不覆盖旧文件。

均匀删除仅是人为缺失假设下的估计分布，不是统计置信区间、不代表作者排除规则。最早/最晚删除说明未知时间选择可能影响趋势，不能声称精确恢复官方9379样本。新结果核准后才写SI，权威排除清单仍需数据作者提供。
