# 路径—强度固定早期窗口联合分析

更新日期：2026-09-06

## 1. 研究问题

既有结果显示长寿命东移型西南涡的生命周期最大强度较高，但生命周期越长、6小时抽样次数越多，越容易取得较大的最大值。本阶段用生成后固定窗口和首对连续观测增长率检验：路径—强度联系是否只是观察机会偏差。

本分析讨论的是联合演变，不预设“路径导致强度”或“强度导致路径”。路径是事件结束后才能完整定义的变量，环流引导、地形、早期强度和环境水汽都可能共同影响结果。

## 2. 数据与方法

- 使用1980–2023年四季完整季节年事件表和700 hPa距地面至少25 hPa的地形安全强度点。
- 强度分别用700 hPa高度亏损和相对涡度表示。
- 构建五类端点：生成后0–6小时首个有效强度、首对连续6小时强度增长、0–12小时峰值、0–24小时峰值、生命周期峰值。
- 0–12小时峰值至少要求2个有效点，0–24小时至少3个；模型同时控制窗口有效点数和首个强度。生命周期模型控制`log(抽样次数+1)`。
- 主路径量为事件最大经度减生成经度，即向东延伸程度；同时控制南北端点位移、生成经纬度和季节。
- 类别敏感性使用既有3路径簇，以Cluster 1为参照；Cluster 2是长寿命、明显东移型。
- 标准化OLS使用季节年聚类稳健标准误，共44个年份簇；同一强度指标和路径项的五个端点做BH-FDR。
- JJA敏感性进一步加入事件生成前−48至−12小时固定区整层水汽辐合异常。

## 3. 样本覆盖与机会偏差

地形安全生命周期强度共有3,606个事件；0–6小时首值2,605个，首对连续6小时增长1,713个，0–12小时峰值1,730个。0–24小时在要求至少3点并控制首值后保留821个。

Cluster 2在0–24小时拥有更多有效点，确认生命周期和较长窗口仍存在路径依赖的可观测性差异。因此不能只比较原始最大值；本报告重点看首值、首对增长和控制点数后的固定窗口模型是否一致。

## 4. 连续路径结果

下表为向东延伸程度每增加1个标准差对应的强度标准差变化；所有区间均使用44个年份簇的聚类稳健估计。

| 端点 | 高度亏损系数（95%区间） | 涡度系数（95%区间） |
|---|---:|---:|
| 首值0–6小时 | +0.148（+0.108至+0.187） | +0.116（+0.075至+0.157） |
| 首对连续6小时增长 | +0.186（+0.127至+0.245） | +0.166（+0.121至+0.211） |
| 峰值0–12小时 | +0.089（+0.061至+0.117） | +0.084（+0.060至+0.109） |
| 峰值0–24小时 | +0.177（+0.119至+0.236） | +0.189（+0.132至+0.246） |
| 生命周期峰值 | +0.241（+0.206至+0.277） | +0.224（+0.182至+0.267） |

十个效应在各自FDR族中均保留。生命周期系数最大，说明观察机会确实放大差异；但首值、首对增长和固定窗口仍稳定为正，说明路径—强度联系并不完全由“长寿命事件更容易抽到大值”解释。

南北端点位移与早期增长多为负：向北位移更多的事件，其首对增长和0–12小时峰值相对偏弱。该结果是次级路径维度，需要在引导气流和地形分层后再解释。

## 5. 路径簇敏感性

控制相同协变量后，Cluster 2相对Cluster 1的高度标准差差异为：首值+0.341、首对增长+0.340、0–12小时峰值+0.166、0–24小时峰值+0.283、生命周期峰值+0.411；涡度对应为+0.276、+0.173、+0.107、+0.312和+0.375。所有Cluster 2对比均通过各自FDR。

类别结果与连续向东延伸量一致，但由于3簇轮廓系数只有0.314，主结论仍应以连续路径量为准，聚类只作为易解释的敏感性展示。

## 6. JJA事件前水汽背景敏感性

在JJA子样本中加入事件前固定区水汽辐合后，向东延伸程度对首对增长和0–12/0–24小时峰值的正联系仍保留。事件前固定区辐合本身对高度端点的标准化系数约0.005–0.017，区间均跨零；对0–24小时涡度峰值为+0.055，95%区间−0.001至+0.111，FDR后不显著。

这并不否定4B的大尺度预条件结果。4B回答“偏强IOBM/WNPAC年份是否更易出现事件前区域汇聚”，本节回答“同一夏季内固定箱水汽异常能否解释单个事件的早期强度差异”。0.5°固定区平均可能无法解析复杂地形附近的局地凝结潜热、边界层和对流过程。

## 7. 对原课题的贡献

1. 将路径—强度联系从生命周期最大值推进到生成初期和固定窗口，直接量化观察机会偏差。
2. 高度亏损与相对涡度给出一致结果，降低单一强度定义导致的偶然性。
3. 连续东移程度和路径簇结果相互支持，避免只依赖轮廓系数较低的聚类。
4. 结果支持“强度—路径协同演变”作为频数—强度—路径联合分析的一个稳定组成部分。
5. 为下一步空间环流诊断提出明确目标：寻找同时有利于早期增强和向东传播的引导气流、斜压/潜热过程，而不是只解释生命周期最大值。

## 8. 局限

- 事件早期强度与最终路径存在时间顺序，但仍不能仅凭回归判定因果方向。
- 固定窗口样本要求事件持续且等压面地形安全，0–24小时样本只有821个，可能代表更持久的一类事件。
- 年份聚类处理同年相关性，但没有消除再分析场与基于ERA5训练/识别轨迹之间的资料依赖。
- 700 hPa在青藏高原东缘仍受地形约束；25 hPa安全阈值是保守但并非唯一选择。
- 本阶段不是温室气体强迫响应分析。
